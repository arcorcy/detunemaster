# Detunemaster

Transposeur de grilles d'accords : transposition, conversion majeur/mineur, capo, notations ABC, latine ou en degrés, et diagrammes guitare, ukulélé et piano au survol.

En ligne : https://detunemaster.netlify.app

## Lancer en local

```bash
python3 -m http.server 4173
```

Puis ouvrir http://localhost:4173. Chaque push sur `main` redéploie le site sur Netlify.
